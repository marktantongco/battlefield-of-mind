# Contributing to AI Blog Platform

Thank you for your interest in contributing! 🎉

## How to Contribute

### 1. Report Bugs
- Check if the bug is already reported in [Issues](https://github.com/yourusername/ai-blog-platform/issues)
- If not, create a new issue with:
  - Clear title
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots if applicable
  - Your environment (OS, Node version, etc.)

### 2. Suggest Features
- Open an issue with the "enhancement" label
- Describe the feature and its use case
- Explain why it would be valuable

### 3. Submit Pull Requests

#### Before You Start
1. Fork the repository
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make sure tests pass: `npm run build`

#### Code Style
- Use TypeScript for type safety
- Follow existing code formatting
- Use meaningful variable names
- Add comments for complex logic

#### Commit Messages
- Use clear, descriptive messages
- Start with verb: "Add", "Fix", "Update", "Remove"
- Examples:
  - ✅ "Add Filipino language support to SEO optimizer"
  - ✅ "Fix donation widget Stripe integration"
  - ❌ "updates"
  - ❌ "fix bug"

#### Pull Request Process
1. Update documentation if needed
2. Add yourself to contributors list
3. Create PR with clear description
4. Link related issues
5. Wait for review

### 4. Improve Documentation
- Fix typos
- Add examples
- Clarify instructions
- Translate to Filipino

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/ai-blog-platform.git
cd ai-blog-platform

# Install dependencies
npm install

# Create branch
git checkout -b feature/amazing-feature

# Make changes and test
npm run dev

# Build to ensure no errors
npm run build

# Commit and push
git add .
git commit -m "Add amazing feature"
git push origin feature/amazing-feature
```
