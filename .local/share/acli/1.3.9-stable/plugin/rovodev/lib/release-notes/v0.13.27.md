# Release Notes - v0.13.27

**Release Date:** January 9, 2025  
**Previous Version:** v0.13.26

## Summary

This release introduces a new interactive model selection feature for the Nemo assistant, improves file system security with automatic temp file access, and optimizes dependencies by removing the heavyweight diskcache library in favor of lighter-weight alternatives.

## New Features

- **Interactive Model Menu**: Added `/models` command in Nemo assistant for easier model selection through an interactive menu interface

## Bug Fixes

- **File System Access**: Fixed issue where shell output temporary files were being blocked by path validation system

## Engineering Improvements

- **Dependency Optimization**: Removed diskcache dependency across multiple packages and replaced with cachetools for lighter-weight in-memory caching
- **Inclusive Language**: Updated function naming from whitelist terminology to allowlist for better inclusivity
- **Performance**: Reduced startup time by eliminating disk I/O operations for cache management
