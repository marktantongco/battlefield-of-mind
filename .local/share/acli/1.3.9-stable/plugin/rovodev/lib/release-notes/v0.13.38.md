# Release Notes - v0.13.38

**Release Date:** January 26, 2026  
**Version:** 0.13.38  
**Previous Version:** 0.13.37

## Summary

This release introduces a major new feature with the interactive review command, along with several bug fixes and improvements to user experience. The release includes enhanced review capabilities with GUI support, improved error handling, and various UI enhancements.

## New Features

- **Interactive Review Command**: Added new interactive review command with GUI mode support and comprehensive test coverage
- **Custom Instructions Support**: Added support for custom instructions in the code review agent
- **GitLab Integration**: Added GitLab comment posting after agent runs
- **User Comments**: Allow user comments in the review interface
- **Enhanced Diagram Interaction**: Added zoom-to-fit scaling functionality and replaced panzoom with react-zoom-pan-pinch for better mermaid diagram handling

## Bug Fixes

- **Confluence Search**: Fixed CQL response parsing and data extraction
- **Review GUI**: Corrected submit button behavior in review interface  
- **CLI Interaction**: Prevented Jira startup messages from displaying in non-interactive mode
- **Comment Requirements**: Required agent comments to have line numbers
- **CORS Configuration**: Added PUT and PATCH to allowed HTTP methods
- **Subagents**: Fixed additional memory file handling to prevent canceling creation flow
- **Web GUI Layout**: Fixed source selection stats layout

## Engineering Improvements

- **Command Restructuring**: Renamed tour command to review for better clarity
- **Code Reuse**: Refactored review command to reuse run command for better maintainability  
- **Nautilus Configuration**: Configured nautilus execution for development vs production modes
- **Pipeline Optimization**: Disabled SonarQube analysis in CI pipeline
- **User Experience**: Clarified upgrade messaging by changing "(requires upgrade)" to "(requires plan upgrade)"
