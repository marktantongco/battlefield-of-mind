# Release Notes - v0.13.19

**Release Date:** December 17, 2025  
**Previous Version:** v0.13.18

## Summary

This release brings significant enhancements to serve mode functionality, improved user experience through better UI messaging, critical security and bug fixes, and comprehensive documentation updates.

## New Features

- **File-based Initial Prompts**: Support for loading initial prompts from JSON files using `file://` prefix in serve mode
- **Enhanced Serve Mode Commands**: Added `/full-context` and `/prompts` command support for better serve mode functionality
- **F1 Racing Animations**: Added engaging F1-style racing and loading animations for CLI startup
- **Session Feedback Analytics**: Enhanced analytics with model ID tracking for better user satisfaction correlation
- **Dynamic Feedback Cooldown**: Added configurable session feedback cooldown delays

## Bug Fixes

- **Security Fix**: Replaced unsafe wildcard patterns in tool permission resolver to prevent potential command injection
- **Confluence Page Updates**: Fixed ADF content normalization issues causing inconsistent page update operations
- **GUI Mode**: Resolved GUI command regression by fixing invalid parameter passing
- **Agent Run Rendering**: Fixed multiple display bugs including memory leaks and code block rendering issues
- **Tool Schema Preservation**: Prevented important tool schema information from being pruned from message history
- **Permission Handling**: Improved handling of long commands with markdown in tool permissions

## User Experience Improvements

- **Tour Experience**: Added confirmation dialog on tab close during tours and clarified tour messaging
- **UI Text Updates**: Replaced intimidating "q: Exit/Quit" with gentler "Esc: Cancel" in menu footers
- **Tool Call Timer**: Enhanced timer to start only when tools are actually executing, not during generation
- **Follow-ups Terminology**: Refactored tour comments to use "follow-ups" terminology consistently

## Documentation Updates

- **Permissions Documentation**: Expanded auto-allowed safe commands list to match implementation
- **Memory Documentation**: Removed documentation for unimplemented memory notes functionality
- **Sessions Documentation**: Added bookmark functionality documentation and best practices
- **Quickstart Guide**: Updated with missing commands and improved guidance
