# Release Notes - v0.13.23

**Release Date:** January 6, 2025  
**Previous Version:** v0.13.22

## Summary

This release introduces major new features including inline task processing with @rovodev comments, plan mode with interactive approval, and comprehensive event hooks system. It also includes significant improvements to terminal setup, UI enhancements, and security fixes.

## New Features

- **Inline Task Processing**: Complete LSP integration for processing @rovodev comments in code with InlineTaskManager and InlineTaskAgent
- **Plan Mode**: Interactive approval workflow allowing users to review and approve implementation plans before execution
- **Enhanced Event Hooks**: Added on_error and on_tool_permission event hooks with separate log file support
- **MCP Environment Variables**: Support for environment variable injection in MCP configuration args and headers
- **Fast/Slow Model Switching**: Implemented SwitchingModel class for dynamic model selection based on task complexity
- **Repetition Detection**: Added safeguards to prevent infinite loops in streaming model output
- **Confluence Improvements**: Enhanced Confluence tooling with comment support and ADF documentation

## User Experience Improvements

- **Enhanced Terminal Setup**: Simplified terminal configuration with automatic shift+enter support and better terminal compatibility
- **Multiline Chat Input**: Replaced simple input widget with sophisticated text area supporting shift+enter for newlines
- **Improved UI Animations**: Better banner handling, startup animations for first-time users, and reduced UI flickering
- **Shell Output Management**: Persist truncated bash output to temporary files and improved output handling

## Bug Fixes

- **Security**: Prevented internal source code disclosure in binary distribution
- **Terminal Compatibility**: Removed iterm2 from shift enter mode to fix compatibility issues
- **UI Fixes**: Fixed sessions progress bar styling, banner re-display prevention, and display multiplier calculations
- **Error Handling**: Improved Google API provider error handling and reduced noisy MCP warnings

## Engineering Improvements

- **Analytics Enhancements**: Added internal conversation logging, CLI startup tracking with Jira parameters, and improved attribute filtering
- **Documentation Updates**: Updated ACP documentation with memory commands and full-context features
- **Code Quality**: Improved formatting, refactored ACP components, and enhanced test coverage
- **Development Tools**: Added .nvmrc file for Node.js version management and textual UI for nemo assist
