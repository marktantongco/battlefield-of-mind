# Release Notes - v0.13.35

**Release Date:** January 22, 2025  
**Version:** 0.13.35  
**Previous Version:** 0.13.34

## Summary

This release introduces significant improvements to the CLI user experience, enhanced subagent capabilities, and new tour functionality. Key highlights include improved code output formatting, better autocomplete functionality, and expanded subagent memory support.

## New Features

- **Enhanced Code Output**: Added new "rich" output format to make markdown mode more copiable while preserving visual formatting
- **Tour UI Enhancements**: Added inline comment UI with diff annotations for better code review experience
- **Subagent Memory Files**: Added support for additional memory files for subagents with workspace lookup functionality
- **Improved Autocomplete**: Enhanced CLI command autocomplete with substring matching and comprehensive test coverage
- **Full-Context Git Access**: Enabled fullcontext subagent to use git commands for historical data retrieval
- **Theme Switching**: Added `/theme` command with dynamic syntax highlighting and theme persistence

## Bug Fixes

- **MCP Stability**: Made atlassian-exp client stateless with retry logic to prevent connection-related issues

## Engineering Improvements

- **Code Quality**: Added linting pre-commit hooks for better code consistency
- **Documentation**: Enhanced configuration documentation
- **Infrastructure**: Improved SCM client architecture with abstract base classes
- **Pipeline Support**: Added code-conseil databricks pipeline support
