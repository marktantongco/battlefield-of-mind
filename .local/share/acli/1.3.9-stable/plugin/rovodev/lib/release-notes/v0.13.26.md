# Release Notes - v0.13.26

**Release Date:** January 8, 2025  
**Previous Version:** v0.13.25

## Summary

This release focuses on bug fixes and user interface improvements, including better display formatting for model credit multipliers, improved clipboard handling, and enhanced Confluence integration stability.

## Bug Fixes

- **Model Display**: Fixed multiplier formatting to display whole numbers without unnecessary decimal places (e.g., "2" instead of "2.0")
- **Confluence Integration**: Enhanced content handling in page creation to properly support both string and object content types
- **Clipboard Management**: Removed noisy exception logging from background clipboard cleaner thread for better user experience

## Engineering Improvements

- **Dependency Optimization**: Migrated Confluence tools from disk-based caching to in-memory TTL cache, reducing external dependencies
- **Error Handling**: Simplified clipboard cleaner error propagation for cleaner exception handling
