# Release Notes: v0.13.29

**Release Date:** January 13, 2026

---

## Overview

This release includes new features for improved user experience, enhanced analytics capabilities, better documentation, and additional evaluation tools. Key highlights include a unified code review agent, enhanced session management, and improved CLI usability.

---

## New Features

- **Unified Code Review Agent**: Added configurable code reviewer agent with support for multiple comment types
- **Event Hooks Management**: Added `/hooks` command for interactive configuration of event hooks that run during specific agent events
- **Session Creation Alias**: Added convenient `/new` alias for creating new sessions
- **PR Search Functionality**: Enhanced MCP Scout with PR search tool featuring hybrid ranking algorithms
- **Analytics Improvements**: Added user-configured LLM model tracking to event attributes
- **Diff Similarity Evaluation**: New LLM-based evaluator for semantic comparison of code patches

---

## Bug Fixes

- **Model Selection**: Fixed duplicate "Auto" model entries appearing in the model selection list

---

## Documentation Updates

- **Quickstart Guide**: Updated documentation with missing commands and flags
- **API Reference**: Added comprehensive V3 API endpoint documentation for session management and agent operations  
- **Prompts Documentation**: Standardized terminology from "instruction" to "prompt" throughout documentation

---

## Engineering Improvements

- **Analytics Refactoring**: Moved session history tracking logic to shared evaluation_utils module for better reusability
- **CI/CD Pipeline**: Added fluid descriptor validation and deployment capabilities
- **Release Process**: Added automated release notes generation for v0.13.28
