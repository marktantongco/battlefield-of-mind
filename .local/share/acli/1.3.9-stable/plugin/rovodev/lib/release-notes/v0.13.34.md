# Release Notes - v0.13.34

**Release Date:** January 20, 2026  
**Version:** 0.13.34  
**Previous Version:** 0.13.33

## Summary

This release includes new search functionality, performance improvements, user experience enhancements, and documentation updates.

## New Features

- **DAC Search Integration**: Added Developer and Admin Content (DAC) search functionality to MCP scout with comprehensive error handling and pagination support
- **Parallel Hook Execution**: Hook commands now execute in parallel instead of sequentially, improving performance when multiple hooks are configured

## Bug Fixes

- **MCP Schema Robustness**: Made get-confluence-page tool robust to MCP schema changes by implementing dynamic metadata processing
- **Session Fork UI**: Hidden empty fork options when no bookmarks are available, preventing confusing "No bookmarks found" messages
- **iTerm2 Integration**: Fixed Shift+Enter key binding issues in iTerm2 through proper plist configuration

## Engineering Improvements

- **String Check Infrastructure**: Reorganized Claude string checks into 15 distinct groups to enable better randomized testing capabilities
- **Documentation Updates**: Updated quickstart documentation to include missing `/new` command and `/bookmark` prompts subcommand
