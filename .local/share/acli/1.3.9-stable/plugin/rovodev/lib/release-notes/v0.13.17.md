# Release Notes - v0.13.17

**Release Date:** December 12, 2025  
**Previous Version:** v0.13.16

## Overview

This release introduces significant improvements to the user interface, model support, and MCP server capabilities. Key highlights include console flickering fixes, new model additions, enhanced web GUI functionality, and improved Jira integration support.

## 🆕 New Features

- **New Model Support**: Added gpt-oss-120b model for enhanced AI capabilities
- **Improved Models Command UI**: Enhanced text and pricing display with clearer auto-select recommendations and credit multiplier information
- **MCP Server Integration**: Added integrations MCP server with feature flag support
- **AcraWorkflowAgent**: New agent to integrate AcraMini with Acra Workflows for improved code review processes

## 🐛 Bug Fixes

- **Console Performance**: Resolved console flickering issues with refresh rate controls and spinner improvements
- **Web GUI Routing**: Fixed SPA fallback routing for GUI web server to improve navigation
- **Tour Content Visibility**: Added footer padding to ensure last tour content is properly visible
- **Header Configuration**: Updated header name from Atl-CloudId to X-RovoDev-CloudId for proper API communication
- **Initialization Order**: Fixed context7 initialization order in CommentGenerationAgent to prevent runtime errors
- **Jira Project Keys**: Enhanced support for alphanumeric Jira project keys in create/update tools

## ⚙️ Engineering Improvements

- **Release Documentation**: Added comprehensive release notes for v0.13.16
- **Code Quality**: Improved initialization patterns and error handling across multiple components
- **Web Interface**: Enhanced user experience with better routing and content display
