# Release Notes - v0.13.11

**Release Date:** December 3, 2025  
**Version:** 0.13.11  

## New Features

- **ADF-compatible Confluence Tools**: Added beta mode support for Atlassian Document Format (ADF) compatible Confluence tools in MCP Atlassian experimental package

## Bug Fixes

- **String Formatting**: Fixed iteration counter message formatting by adding proper newlines in ACRA Mini agent callback
- **Analytics Filtering**: Stopped sending tool call events to devai-axis to reduce unnecessary analytics noise
- **Sessions UTF-8 Encoding**: Ensured consistent UTF-8 encoding and improved function naming in sessions module

## Improvements

- **Documentation Updates**: Enhanced documentation across multiple areas including quickstart guide with help subcommand, serve API documentation with v3/set-site-url endpoint, permissions documentation with enhanced command coverage, memory documentation with acli prefix updates, and sessions documentation with deprecation notes for autoRestore config setting
