# Release Notes - v0.13.20

**Release Date:** December 18, 2025  
**Previous Version:** v0.13.19

## Summary

This release introduces significant new features including markdown mode with clipboard support, event hooks configuration, and enhanced bash permissions. It also includes improvements to analytics, evaluation capabilities, and user experience enhancements.

## New Features

- **Markdown Mode with Clipboard Support**: Re-enabled full markdown mode with clipboard copy functionality using pyperclip
- **Event Hooks Configuration**: Added configuration skeleton for event hooks with support for on_complete, on_error, and on_permission_request events
- **Enhanced Bash Permissions**: Added support for /dev/null redirections and background execution in auto-permitted commands
- **Analytics Control**: Added server-side flag to disable git-ai analytics collection
- **CLI Evaluation Support**: Enabled offline evaluation capabilities for the cli-rovodev agent
- **Tour Agent Comments**: Added functionality for tour agent to leave comments on code changes

## User Experience Improvements

- **System Context**: Added current date and time information to agent system prompt for better temporal awareness
- **Syntax Highlighting**: Improved syntax highlighting for light mode themes in code-nemo with dark/light mode detection

## Engineering Improvements

- **Logging Enhancement**: Added InterceptHandler to route standard Python logging to loguru for better log management
