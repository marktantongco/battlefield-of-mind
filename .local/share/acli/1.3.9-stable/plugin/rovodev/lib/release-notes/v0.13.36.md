# Release Notes: v0.13.36

**Release Date:** January 23, 2026

---

## Overview

This release brings significant performance improvements, new functionality, and enhanced developer experience. Key highlights include optimized MCP startup times, new review command for automated code reviews, improved user interface with undo functionality, and comprehensive documentation updates across multiple components.

---

## New Features

- **Automated Code Review Command**: Added new `/review` command for automated code reviews using the UnifiedCodeReviewerAgent with git diff analysis capabilities
- **Chat Input Undo Functionality**: Added Ctrl-Z keyboard shortcut to undo text changes in the chat input prompt
- **GitLab REST Client**: Implemented comprehensive GitLab REST client with merge request and comment support for enhanced SCM integration
- **Subagent Loading in Conseil**: Added flexible subagent loading with name matching support for enhanced evaluation capabilities
- **Automatic Configuration Pruning**: Implemented automatic detection and removal of deprecated configuration fields during config loading
- **SweBench Evaluation with Authentication**: Added internal SweBench evaluation support with Bitbucket authentication for private repositories
- **Artifact Deserialization**: Enabled artifact deserialization in session context for improved data handling

---

## Performance Improvements

- **MCP Scout Startup Optimization**: Significantly improved Scout MCP startup times by pre-installing tools with `uv tool install` and using offline mode instead of repeated `uvx` installations

---

## Bug Fixes

- **Bash Command Parser**: Fixed issue where bash command parser incorrectly extracted '#' as command name when processing comments in bash commands
- **Conseil Session Logging**: Ensured session logs are always dumped for failed runs by moving result dumping to finally block with proper configuration

---

## Documentation Updates

- **MCP Documentation**: Updated MCP documentation with interactive interface details and command clarifications
- **Permissions Documentation**: Updated permissions documentation to match current implementation with corrected examples
- **Sessions Documentation**: Added `/new` command alias and updated bookmark documentation with improved examples
- **Quickstart Documentation**: Updated quickstart guide with missing commands and clarifications for better user onboarding
- **String Checks Configuration**: Updated string checks markdown to synchronize with current Statsig configuration

---

## Engineering Improvements

- **SonarQube Integration**: Added comprehensive SonarQube code quality analysis with coverage aggregation across all test platforms and quality gate checks
- **Event Hooks Simplification**: Removed the `enabled` field from event hooks configuration, making event hooks always enabled by default and simplifying the configuration system
