# Release Notes - v0.13.15

**Release Date:** December 9, 2025  
**Previous Version:** v0.13.14

## Overview

This release introduces major new functionality including an interactive code review tour system, secure OAuth token persistence, enhanced Jira integration, and improved user experience features. Key highlights include the new `/tour` command for guided code reviews, persistent OAuth credentials, and streamlined CLI workflows.

## 🆕 New Features

- **Interactive Code Review Tour**: Complete `/tour` command system with web-based UI for reviewing code changes interactively
- **Secure OAuth Token Persistence**: OAuth credentials now securely stored using system keyring (macOS Keychain, Linux Secret Service, Windows Credential Manager)
- **Jira CLI Integration**: New `--jira` flag to start CLI sessions directly with specific Jira tickets
- **Enhanced Multiline Input**: Added Ctrl+O keyboard shortcut for inserting newlines in chat prompts
- **Jira Attachment Support**: Full upload and download functionality for Jira issue attachments
- **Full-Context Mode**: New ACP command for comprehensive project context gathering

## 🐛 Bug Fixes

- Fixed Jira callback registration and data handling issues
- Resolved editor mode UI glitches
- Improved OAuth token exchange error handling
- Enhanced feedback message clarity with session-specific context

## ⚙️ Engineering Improvements

- Optimized GUI API server port discovery with development proxy support
- Refactored tour agent constants and added model settings
- Enhanced memory documentation and reference expansion features
- Improved string validation utilities with HTML editor
- Updated MCP Scout configuration and enablement
