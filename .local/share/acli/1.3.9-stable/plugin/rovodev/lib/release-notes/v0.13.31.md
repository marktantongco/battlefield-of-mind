# Release Notes: v0.13.31

**Release Date:** January 16, 2026

---

## Overview

This release includes important bug fixes for MCP server functionality, enhanced validation rules for Claude AI agents, improved evaluation metrics for code quality assessment, and comprehensive documentation updates for configuration options.

---

## New Features

- **Enhanced Evaluation Metrics**: Added completed runs metrics for file-based quality evaluation in Conseil, providing better insights into code review performance by filtering out empty patches

---

## Bug Fixes

- **MCP Server Restoration**: Re-enabled Scout MCP server availability check that was accidentally disabled, restoring proper Scout functionality for internal users

---

## Documentation Updates

- **Comprehensive Configuration Documentation**: Updated config documentation with previously missing fields and sections including Event Hooks, Atlassian Billing Site, experimental features, MCP server configurations, and tool permissions

---

## Engineering Improvements

- **Enhanced Validation Rules**: Split Claude agent groups into separate main agent and subagent categories with stricter string validation rules and improved pattern matching for better code quality enforcement
