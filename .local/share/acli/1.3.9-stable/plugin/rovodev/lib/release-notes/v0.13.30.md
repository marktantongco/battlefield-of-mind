# Release Notes: v0.13.30

**Release Date:** January 16, 2026

---

## Overview

This release focuses on enhanced user experience, improved authentication capabilities, workspace state management, and CLI usability improvements. Key highlights include OIDC authentication support, interactive git workspace restoration, enhanced tool configuration options, and improved subagent functionality.

---

## New Features

- **OIDC Authentication**: Added OpenID Connect token support for Bitbucket Pipelines authentication with priority handling
- **Interactive Git Restore**: Added interactive git workspace restoration when switching between sessions created on different branches
- **Workspace State Tracking**: Enhanced session bookmarks to capture and track git workspace state (branch name and commit SHA)
- **Tool Result Visibility Configuration**: Added per-tool configuration for controlling which tools display their results in CLI output
- **Safe Bash Commands in Ask Mode**: Allow safe, read-only bash commands (like `ls`, `cat`, `grep`) in ask mode while blocking destructive operations
- **Shift-Tab Agent Mode Cycling**: Added ability to cycle through agent modes using Shift+Tab with persistence across chat messages
- **Subagent Model Information**: Enhanced `/subagents` command to display model information alongside each subagent in the selection menu
- **Restricted Mode for Automations**: Added `ROVO_DEV_RESTRICTED_MODE` environment variable to disable Atlassian connections and limit MCP servers
- **String Checks Enhancements**: Added markdown export functionality, custom group naming, and default values for string checks editor
- **Test File Filtering**: Added functionality to filter out test files from diff patches in PolyBench evaluations

---

## Bug Fixes

- **Configuration Warnings**: Fixed repeated warnings for unknown configuration fields by implementing one-time warning system
- **WSL Performance**: Removed auto clipboard fixer functionality due to performance issues on Windows Subsystem for Linux
- **Session Metadata Safety**: Prevented session dumps from overwriting existing metadata.json files with stale data

---

## Documentation Updates

- **Permissions Documentation**: Updated permissions documentation with implementation details and command examples
- **Quickstart Guide**: Added missing `/hooks` command to quickstart documentation
- **Ask Questions Tool**: Improved documentation and output formatting for the `ask_user_questions` tool

---

## Engineering Improvements

- **Performance Optimization**: Moved blocking network requests to background threads to improve CLI startup performance
- **Code Organization**: Moved JSON utility functions from package-specific locations to shared code-common package
- **Unified Agent Cleanup**: Enhanced unified code review agent with strong typing and improved system prompts
- **MCP Scout Updates**: Added cachetools dependency and version bumps for enhanced functionality
- **Subagent Tool Restrictions**: Disabled PR and code search tools in full-context-mode subagent due to external shipment constraints

---
