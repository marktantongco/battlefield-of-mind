# Release Notes - v0.13.25

**Release Date:** January 7, 2025  
**Previous Version:** v0.13.24

## Summary

This release introduces structured output support for programmatic use, enhanced user interface improvements for navigation and session management, and several important bug fixes for session replay and AI model reliability.

## New Features

- **Structured Output Support**: Added `--output-schema` and `--output-file` parameters enabling programmatic use with JSON schema validation
- **Enhanced Bookmark Management**: Interactive prompt history navigation with checkpoint rollback and session forking capabilities
- **Improved Navigation**: Added Ctrl-P/Ctrl-N keyboard shortcuts for fuzzy matcher navigation following editor conventions

## Bug Fixes

- **Session Replay**: Fixed conversation buffer preservation when using `--restore` argument for proper session replay functionality
- **AI Model Reliability**: Resolved repetitive token issues for Google/Gemini models by moving detection to model-specific wrapper

## Engineering Improvements

- **Analytics Enhancement**: Added event hook usage tracking with privacy controls and improved observability
- **Architecture**: Refactored repetition detection to be provider-specific rather than universal, improving model wrapper architecture
