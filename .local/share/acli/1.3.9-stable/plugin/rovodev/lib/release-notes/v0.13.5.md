# Rovo Dev CLI v0.13.5 (2025-11-24)

## Summary
This release focuses on API enhancements, documentation improvements, and significant architectural refactoring. Key highlights include custom session titles for serve mode, improved model context handling, and removal of the nest_asyncio dependency for better async performance.

## New Features
- **Custom Session Titles**: Added support for custom titles when creating sessions through serve API endpoints
- **Reasoning Token Metrics**: Added new reasoning tokens calculation for evaluation metrics
- **Enhanced Model Context Retrieval**: Integrated with LiteLLM for real-time model context limit data with caching

## Bug Fixes
- Fixed interactive mode detection in arun function to properly handle CLI execution context

## Engineering Improvements
- **Async Architecture Overhaul**: Removed nest_asyncio dependency and implemented new MCPServerManager for better lifecycle management
- **Documentation Updates**: Enhanced API documentation with agent mode endpoints and updated permissions/prompts documentation
- **Test Improvements**: Removed unnecessary debug code and added timeout configuration for MCP tests
