# Release Notes - v0.13.14

**Release Date:** December 4, 2025  
**Version:** 0.13.14  

## New Features

- **Full Context Slash Command**: Added `/full-context` slash command that allows users to invoke the Full Context Mode subagent to gather project context from Atlassian tools (Jira, Confluence) without solving problems

## Bug Fixes

- **Git AI Path Consistency**: Fixed path inconsistency in the Nautilus module's git-ai binary path resolution, ensuring both stats-delta and checkpointing features use the same standardized location

## Improvements

- **UI Syntax Highlighting**: Enhanced UI with syntax highlighting support for "fullcontext" and "full-context" keywords
- **Test Coverage**: Added comprehensive test coverage for the new full-context slash command functionality

## Technical Details

- **81538a1bf**: fix(nautilus): resolve git-ai v2 path inconsistency - Fixed a path inconsistency in the Nautilus module's `_get_git_ai_path()` function. Changed the v2 git-ai binary path from `git-ai-v2/git-ai` to `git-ai/v2/git-ai` to match the directory structure used in the main `git_ai.py` module, ensuring both stats-delta and checkpointing features look for the git-ai binary in the same standardized location.
- **9c1a26b0d**: feat(cli): add /full-context slash command for project context gathering - Added a new `/full-context` slash command that allows users to invoke the Full Context Mode subagent to gather project context from Atlassian tools (Jira, Confluence) without solving problems. Includes comprehensive test coverage and UI syntax highlighting for the "fullcontext" and "full-context" keywords.
