# Release Notes - v0.13.18

**Release Date:** December 15, 2025  
**Previous Version:** v0.13.17

## Overview

This release introduces significant enhancements to the tour functionality and session management capabilities. Key highlights include comprehensive tour source selection features, interactive session bookmarking with forking support, improved CI/CD evaluation capabilities, and various UI improvements for better user experience.

## 🆕 New Features

- **Tour Source Selection**: Complete tour functionality with diff source selection, state persistence, and uncommitted changes support
- **Interactive Session Bookmarking**: New `/bookmark` command with interactive menu and session fork functionality
- **Code-Conseil CI Pipeline**: Added evaluation pipeline step for automated code quality assessments
- **Enhanced Feedback System**: "Skip for now" option with optimized cooldown logic for session feedback

## 🐛 Bug Fixes

- **UI Text Improvements**: Updated directories menu footer text from "q: Exit" to "Esc: Cancel" for clarity

## ⚙️ Engineering Improvements

- **Tour Architecture**: Comprehensive refactoring with unified diff source handling and improved state management
- **Callback System**: Removed singleton pattern from CLICallback for better architecture
- **Documentation**: Enhanced Mermaid diagram generation instructions for tour functionality
- **UI Responsiveness**: Replaced static panels with spinners during tour startup for better user feedback
