# Release Notes - v0.13.28

**Release Date:** January 9, 2025  
**Previous Version:** v0.13.27

## Summary

This release focuses on performance improvements, infrastructure enhancements, and bug fixes. Key highlights include significantly faster CLI startup times through dynamic imports, improved Linux binary compatibility with manylinux builds, and a fix for Confluence page content truncation issues.

## New Features

- **Analytics Enhancement**: Added model name extraction from pydantic_ai agents for improved analytics tracking

## Bug Fixes

- **Confluence Pages**: Resolved content truncation issue by automatically saving large pages to temporary files while showing truncated previews
- **CI Pipeline**: Fixed main branch pipeline configuration and Windows test issues

## Performance Improvements

- **CLI Startup**: Implemented dynamic imports for significantly faster command startup, especially benefiting config, log, mcp, and --version commands

## Engineering Improvements

- **Linux Compatibility**: Added manylinux builds for improved binary compatibility across Linux distributions
- **Code Cleanup**: Removed legacy haiku 4.5 migration feature flag and associated logic
