# Battlefield of the Mind - Interactive Recovery Journey

An interactive web application designed to guide users through personal conflict resolution and mental transformation using AI-assisted recovery frameworks.

## Features

- 🧠 **Battlefield of the Mind** - Identify and reframe limiting thought patterns
- 🧼 **Cleanup Process** - 4-step relationship repair framework
- ✨ **Openly Mended Paradigm** - Transform scars into bridges
- 🚀 **Mission Architecture** - Build AI-driven recovery institutions

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```

Visit `/battlefield` to access the interactive recovery journey.
