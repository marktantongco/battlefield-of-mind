## 🎯 Deploy Now (2 Minutes)

### Step 1: Visit Vercel Dashboard
Go to: **https://vercel.com/new**

### Step 2: Import Repository
- Click "Import Git Repository"
- Select: `marktantongco/battlefield-of-mind`
- Or use this direct link: https://vercel.com/new/git/external?repository-url=https://github.com/marktantongco/battlefield-of-mind

### Step 3: Configure (Auto-detected)
Vercel will automatically detect:
- ✅ Framework: Next.js
- ✅ Build Command: `next build`
- ✅ Output Directory: `.next`

### Step 4: Add Environment Variables (Optional)
Click "Environment Variables" and add:
```
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-KRCBJY380T
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
NEXT_PUBLIC_APP_NAME=Battlefield of the Mind
```

### Step 5: Deploy!
Click the big "Deploy" button and wait 2-3 minutes.

The dashboard will show detailed error logs. Common fixes:
1. Make sure all environment variables are added
2. Check that the repository is public or Vercel has access
3. Verify Node.js version is 18.x or higher
